# Wires

Промо-сайт линейки медицинских изделий и средств ухода, собранный как статический сайт на [Eleventy](https://www.11ty.dev/) с шаблонами Nunjucks, SCSS и vanilla JavaScript.

## Что внутри

Сайт состоит из нескольких продуктовых страниц:

- **Пеларго Про** — главная страница с описанием состава, свойств и преимуществ продукта.
- **Фамисепт** — страница спрея для интимной гигиены.
- **СкинПро** — страница продукта с инструкцией по применению.
- **Трофикол** — страница мази с подробной инструкцией по медицинскому применению.

Интерфейс включает адаптивную верстку, слайдеры, мобильное меню, модальные окна заказа и формы обратной связи.

## Стек

- [Eleventy 3](https://www.11ty.dev/) — генерация статических HTML-страниц.
- [Nunjucks](https://mozilla.github.io/nunjucks/) — шаблоны и переиспользуемые компоненты.
- SCSS/CSS — стилизация и адаптивная верстка.
- Vanilla JavaScript — интерактивные элементы без frontend-фреймворков.
- ESLint — проверка JavaScript.
- Prettier — форматирование исходников.
- GitHub Actions + GitHub Pages — автоматическая сборка и публикация сайта.

## Требования

- Node.js **22+**
- npm

Версия Node.js 22 используется в workflow деплоя GitHub Pages.

## Установка

Клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/rudanastasia/wires.git
cd wires
npm ci
```

## Локальная разработка

Запустите Eleventy в режиме разработки:

```bash
npm start
```

После запуска Eleventy поднимет локальный сервер с автоматической пересборкой при изменении исходников.

## Сборка

Для создания production-версии сайта:

```bash
npm run build
```

Готовый статический сайт будет помещён в директорию `dist/`.

## Проверка кода

### ESLint

Проверка JavaScript:

```bash
npm run lint
```

Автоматическое исправление доступных проблем:

```bash
npm run lint:fix
```

### Prettier

Форматирование файлов:

```bash
npm run format
```

Проверка форматирования без изменения файлов:

```bash
npm run format:check
```

### Шаблоны

Общий layout находится в `src/_includes/layout.njk`. Повторяющиеся элементы страницы вынесены в partials:

- header;
- footer;
- мобильное меню;
- модальные окна заказа;
- форма обратной связи.

### Статические ресурсы

Каталоги `src/assets`, `src/css` и `src/js` копируются в итоговую сборку без дополнительной обработки. Это настроено в `eleventy.config.js`.

## Деплой

Проект автоматически публикуется через GitHub Actions.

Workflow находится в:

```text
.github/workflows/static.yml
```

При push в ветку `main` workflow:

1. устанавливает Node.js 22;
2. устанавливает зависимости через `npm ci`;
3. собирает сайт командой `npm run build`;
4. загружает содержимое `dist/` как artifact;
5. публикует artifact через GitHub Pages.

Сборку также можно запустить вручную из GitHub Actions.

## Добавление страницы

Чтобы добавить новую страницу:

1. Создайте новый `.njk`-файл в `src/`.
2. Подключите общий layout через front matter.
3. Укажите `title`, `description` и `permalink`.
4. Добавьте необходимые стили в `src/css/`.
5. Если нужна интерактивность, добавьте JavaScript в `src/js/`.
6. Добавьте изображения в соответствующий каталог `src/assets/img/`.
7. Проверьте проект командами:

```bash
npm run lint
npm run format:check
npm run build
```
